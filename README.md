# BIS Chat

**BIS Chat** is an AI-powered standards intelligence platform for the Bureau of Indian Standards ecosystem. It bridges the gap between the vast catalogue of Indian Standards and the people who use them — manufacturers, testing laboratories, regulators, consumers, researchers, and students — turning standards queries into structured, cited answers.

## What is BIS Chat?

At its core, BIS Chat is a research-first interface for navigating standards knowledge. Ask about an IS code, certification requirement, or product category, and receive clear answers backed by verifiable citations from official standards sources.

### Core Pillars

- **Evidence-Based Answers**: Every response is backed by verifiable citations. The platform natively supports authoritative sources including **BIS (Indian Standards), ISO, and IEC**.
- **The Standards Vault**: A dedicated space for compliance research. Save critical clauses, source citations, and standards references for later review or inclusion in reports.
- **Journal-Grade Readability**: A clean, high-legibility interface with a distraction-free environment for deep reading of technical content.
- **Flexible Aesthetics**: Toggle between a **Modern** geometric design (fast-paced digital workflows) and a **Classic** serif-based design (long-form reading), with calibrated Light and Dark modes.

## Key Features

- **Multi-Source Synthesis**: Aggregates and cross-references BIS, ISO, and IEC documents in real time.
- **Intelligent Citations**: Clickable, categorized sources so every claim can be verified against the original standard.
- **Dynamic Themes**: Fully responsive Light and Dark modes in the BIS ocean palette (deep navy, azure, cyan).
- **Advanced State Management**: Persists research progress and aesthetic preferences locally for a seamless, "always-on" experience.
